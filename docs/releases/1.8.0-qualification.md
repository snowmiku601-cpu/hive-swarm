## Independent review

The fresh whole-branch Swarm review identified five material defects and one event-stream defect. Integration addresses cancellation teardown, permission-wait identity and recovery, worktree path rendering, Windows Node binding, invalid outcome poisoning and SSE backlog cursors. Each correction has a behavioral regression. The independent follow-up approved all six corrections. The recovered-turn regression also checks normal status/read/post commands, wrong-turn refusal, one settlement and zero repeated prompts; a conflicting stored pending turn is refused.

The real Desktop smoke then found undeclared Cordis dependencies and inherited Standard-preset services omitted by the initial resolver. Strict Context regressions reproduced Host and client access failures; the adapter now prefers preset-local enforcement and otherwise uses the actual Agent's effective service context. It still refuses missing or unconfined private services. A fresh scoped review and a separate SDK contract review approved these corrections before the final build.

Older Windows Node builds also exposed failures in the test fixtures themselves: 24.2.0 `fs.rmSync` could leave Unicode-path files untouched, and 22.19.0 recursive `fs.cpSync` could abort the process. Test setup/teardown now uses explicit file copy, unlink and directory removal. An asynchronous real-Git fixture now uses a bounded wall-clock deadline instead of a subsecond polling count. These changes preserve the product assertions.
